# نموذج طلب — Nota de Pedido

أداة بسيطة لتعبئة «نموذج طلب» المعتمد وتوقيعه، ثم تنزيله بصيغة **PDF (A4)** وبصيغة **صورة PNG**.

## الاستعمال
1. افتح الملف `index.html` في أي متصفح (حاسوب أو هاتف) — يعمل دون إنترنت، فكل ما يحتاجه مضمَّن فيه.
2. املأ: التاريخ، وتفاصيل الطلب، والاسم، والجهة، ثم ارسم التوقيع أو ارفع صورته.
3. راجع المعاينة، ثم اضغط **«موافق — إنشاء PDF وصورة»**.

- يُوزَّع نص التفاصيل تلقائيًا على الأسطر المنقّطة الخمسة، ويُصغَّر الخط إذا طال النص، مع تنبيه إن تجاوز المساحة.
- الفقرة العربية تُكتب من اليمين، والفقرة الإسبانية/اللاتينية من اليسار تلقائيًا.
- يمكن حفظ الاسم والجهة والتوقيع على الجهاز نفسه لإعادة استعمالها.

## للمطوّر
- `app.template.html`: الشيفرة المصدرية. `form-template.jpg`: صورة النموذج.
- `vendor/`: خط Amiri (رخصة OFL) ومكتبة jsPDF 2.5.1 (رخصة MIT).
- بعد أي تعديل: `python3 build.py` لإعادة توليد `index.html`.
- مواضع الحقول محددة في الكائن `G` داخل الشيفرة (بإحداثيات الصورة الأصلية 1059×1486).
