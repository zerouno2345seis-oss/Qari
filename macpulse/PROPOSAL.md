# MacPulse — مقترح المشروع

برنامج Electron لنظام macOS لمراقبة الأداء وتحليل العتاد وتحسين النظام.

## 1. الوحدات الأساسية

| الوحدة | المحتوى | المصدر التقني |
|---|---|---|
| لوحة المعلومات | CPU، الذاكرة، القرص، الشبكة، البطارية في رسوم حية | `systeminformation` |
| المعالج | الحِمل لكل نواة (P/E-cores في Apple Silicon)، التردد، المعالجات المعلّقة | `systeminformation`، `powermetrics` |
| الذاكرة | Wired/Active/Compressed/Swap وضغط الذاكرة (Memory Pressure) | `vm_stat`، `memory_pressure`، `sysctl` |
| GPU | الحِمل والذاكرة والتردد | `powermetrics`، `ioreg` |
| الحرارة والمراوح | حرارة CPU/GPU/SSD/البطارية وسرعة المراوح | `powermetrics`، SMC عبر وحدة native |
| البطارية | الدورات، الصحة، السعة، معدل التفريغ، الواط | `ioreg -r -c AppleSmartBattery` |
| القرص | المساحة، قراءة/كتابة، صحة SSD (SMART) | `diskutil`، `smartctl` |
| الشبكة | الاستهلاك لكل تطبيق، الاتصالات النشطة | `nettop`، `lsof -i` |
| العمليات | الأعلى استهلاكًا، شجرة العمليات، إنهاء/تجميد، عمليات الخلفية | `ps`، `systeminformation` |
| بدء التشغيل | Login Items وLaunchAgents/Daemons مع تعطيلها | `~/Library/LaunchAgents`، `launchctl` |
| التنظيف | caches، سجلات، Xcode DerivedData، Homebrew، npm، مخلفات التطبيقات، المكرّرات والملفات الكبيرة | مسح مع **معاينة وتأكيد** ونقل للسلة لا حذف نهائي |
| التوصيات | محرك قواعد يترجم القياسات إلى نصائح (مثال: «ضغط الذاكرة أحمر لأن Chrome يستهلك 4GB») | منطق داخلي |
| إمكانيات الجهاز | ملف تعريف كامل: الطراز، الشريحة، الأنوية، RAM، GPU، الشاشة، المنافذ، وتقدير للأعمال المناسبة له | `system_profiler -json` |
| التنبيهات والسجل | تنبيه عند الحرارة/الذاكرة، سجل تاريخي (SQLite)، تصدير CSV/PDF | `better-sqlite3` |
| شريط القائمة | أيقونة Menu Bar بملخص سريع | `Tray` |

## 2. المعمارية

- **Main process:** جمع القياسات كل 1–2 ثانية، وتنفيذ الأوامر، وإدارة الصلاحيات.
- **Preload:** جسر IPC محدود بـ `contextBridge` (`contextIsolation` مفعّل، و`nodeIntegration` معطّل).
- **Renderer:** React + Vite + Recharts أو uPlot للرسوم الحية.
- **Helper مميّز (لاحقًا):** أداة صغيرة موقّعة بصلاحيات root عبر `SMJobBless` لـ `powermetrics` ودرجات الحرارة.
- **تخزين:** SQLite للسجل التاريخي.

## 3. تنبيهات تقنية مهمة

- درجات الحرارة والمراوح على Apple Silicon تحتاج `powermetrics` (صلاحيات root) أو قراءة SMC؛ `systeminformation` وحده كثيرًا ما يعيد قيمة فارغة هناك.
- التنظيف عملية خطرة: يلزم وضع «معاينة أولًا»، وقائمة بيضاء للمسارات، ونقل للسلة.
- التوزيع خارج App Store يتطلب توقيع الكود وNotarization؛ أما داخله فيمنع الـ sandbox معظم هذه الميزات.
- لا يمكن اختبار القياسات على Linux، فالتشغيل الفعلي والاختبار يكونان على جهاز Mac.

## 4. خارطة الطريق

1. **MVP:** لوحة حية (CPU/RAM/Disk/Net/Battery) + قائمة العمليات + Menu Bar.
2. **v0.2:** الحرارة والمراوح والـ GPU عبر helper، وصفحة إمكانيات الجهاز.
3. **v0.3:** منظّف الـ cache مع المعاينة وبدء التشغيل.
4. **v0.4:** التوصيات الذكية والسجل التاريخي والتنبيهات.
5. **v1.0:** التوقيع وNotarization والتحديث التلقائي (`electron-updater`).

## 5. ما أُنشئ الآن

هيكل أولي يعمل بعد `npm install && npm start` على macOS: نافذة وIPC آمن ولقطة قياسات (حمل المعالج، الذاكرة، الحرارة، أعلى 10 عمليات). لم يُشغَّل هنا لأن البيئة Linux.
